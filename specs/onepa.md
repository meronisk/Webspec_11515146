# 綠天咖啡網站｜逆向詳細規格

> 來源檔案：`WebPage_11515146/refined/index.html`  
> 文件用途：記錄目前單頁網站的內容、版面、視覺與互動，供後續精確修改或重新製作。  
> 規格以來源 HTML 實際呈現為準；門市與產品資料屬頁面文案。

## 1. 專案概述

| 項目 | 規格 |
|---|---|
| 品牌名稱 | 綠天咖啡（GREEN SKY COFFEE） |
| 網站類型 | 精品手沖咖啡品牌形象與產品介紹單頁網站 |
| 語言 | 繁體中文，文件語言為 `zh-Hant` |
| 目標受眾 | 重視咖啡品質、單一產區風味與手沖體驗的消費者 |
| 網站目的 | 推廣精品手沖咖啡與品牌，介紹產地、當季咖啡豆、沖煮特色及門市 |
| 品牌印象 | 自然、清新、有質感；沉穩綠色搭配米白與淺棕色 |
| 核心訊息 | 從產地到杯中，透過小批次烘焙與細緻手沖呈現咖啡風土 |
| 頁面形式 | 單一 `index.html`；CSS 與 JavaScript 內嵌，不需後端 |

文案語氣安靜、細緻，以產地、土壤、海拔、風味和沖煮節奏描述咖啡。避免強促銷語氣。英文輔助字串使用短句、大寫與較寬字距。

## 2. 技術與資源

- 使用 HTML5、原生 CSS 與原生 JavaScript。
- 文件內含一個主要 `<style>` 區塊與一個頁尾 `<script>`。
- 外部字體為 Google Fonts：`Noto Sans TC`、`Noto Serif TC`、`DM Mono`；若網路字體不可用，仍須以通用 sans-serif 字體顯示。
- Hero 山景、咖啡枝葉與咖啡豆、產地山景、咖啡袋、手沖器具及門市圖卡均以 CSS 形狀、漸層與幾何構成，不依賴照片或圖片檔。
- 導覽與主要 CTA 使用同頁錨點；門市預約和電子郵件使用 `mailto:`。
- 版面容器 `.container` 最大寬度 1140px，左右至少保留 26px；手機版左右至少保留 17px。

## 3. 文件、SEO 與字體

- `html` 使用 `lang="zh-Hant"`、UTF-8 編碼及響應式 viewport。
- 頁面標題：`綠天咖啡｜從產地，到杯中的一片綠`。
- Description 說明綠天咖啡以小批次烘焙與手沖呈現精品咖啡豆的產地風土。
- 全站內文使用 Noto Sans TC，標題與品牌字樣使用 Noto Serif TC，英文標籤與數字使用 DM Mono。
- 預設平滑捲動；當系統偏好減少動態效果時停用平滑捲動與進場動畫。
- 連結、按鈕和輸入欄需有明顯 `:focus-visible` 外框，外框為 3px 黃綠色並留 3px 間距。

## 4. 視覺系統

### 4.1 色彩

| CSS Token | 色碼 | 用途 |
|---|---|---|
| `--forest` | `#17382b` | Hero、沖煮區、品牌深綠 |
| `--deep-forest` | `#0e291f` | Footer、Toast 深色底 |
| `--moss` | `#426a4a` | 標題重點、連結、按鈕文字 |
| `--leaf` | `#9aaa72` | 綠色裝飾與互動提示 |
| `--cream` | `#f4f1e8` | 頁面暖米色底、選豆區 |
| `--paper` | `#fbfaf5` | 內容卡片、品牌故事與門市區 |
| `--oat` | `#ddca9e` | 主要 CTA 的淺棕米金色 |
| `--clay` | `#ad7655` | 咖啡棕與次要互動色 |
| `--ink` | `#26342b` | 主要文字 |
| `--muted` | `#69776e` | 內文次要文字 |
| `--line` | `#d9ddd1` | 邊框、分隔線 |

主要陰影為 `0 20px 50px rgba(18, 45, 32, .13)`。整體採低彩度自然色；深綠區塊以淡黃綠作為對比文字和圖形。

### 4.2 字級與元件風格

- Hero 主標使用 Noto Serif TC，粗細 900，桌面字級 `clamp(43px, 5.5vw, 70px)`；手機約 40px。
- 區塊標題使用 Noto Serif TC，粗細 700，字級 `clamp(30px, 4vw, 48px)`。
- 內文以 15px 為主，行高 1.7，次要說明採 muted 色。
- 英文 eyebrow 通常為 DM Mono 11px、字距約 `.12em`，左側有 26px 細線。
- 按鈕為方角或近直角（1px 圓角）、最小高度 50px；主要按鈕使用 oat 色底及深綠字。
- 卡片與區塊以留白、細邊框和柔和陰影塑造精品感，不使用大量圓角。

## 5. 網頁結構與內容

頁面依序包含：透明疊於 Hero 的 Header、Hero、品牌故事、當季選豆、沖煮方式、門市資訊及 Footer。主要區塊錨點為 `#top`、`#story`、`#selection`、`#brew`、`#visit`。

### 5.1 Header 與導覽

**結構**

- Header 位於頁首，絕對定位於 Hero 上方，滿版寬度，底部為半透明白色細線。
- 導覽列高度至少 76px，內容置於 1140px `.container`。
- 品牌連結包含 CSS 葉片／種子形符號、中文「綠天咖啡」及小字 `GREEN SKY COFFEE`，點擊回到 `#top`。
- 導覽項目依序為「咖啡介紹」→ `#story`、「產地選豆」→ `#selection`、「沖煮特色」→ `#brew`、「門市資訊」→ `#visit`。
- 「門市資訊」使用白色描邊 CTA 樣式。
- 窄螢幕顯示漢堡按鈕 `☰`；按鈕提供 `aria-label`、`aria-expanded` 及 `aria-controls="navLinks"`。

一般導覽項 hover 時以綠色細線由左至右展開；CTA hover 時變為白底深綠字。品牌圖樣為裝飾元素，使用 `aria-hidden="true"`。

## 6. 互動行為

### 6.1 導覽選單

- 在寬度 840px 以下顯示漢堡按鈕，導覽連結改為深綠底的展開式選單。
- 初始收合；點擊切換 `.open`，並同步更新 `aria-expanded`、`aria-label` 與圖示（`☰`／`×`）。
- 點擊任一導覽連結後收合選單，還原漢堡圖示和無障礙狀態。
- 選單以 `max-height` 動畫展開，最大高度 300px。

### 6.2 商品收藏 Toast

- Toast 固定於右下方 22px，深森林底色，左側有 3px oat 色線，具柔和陰影。
- 使用 `role="status"` 與 `aria-live="polite"`，預設透明並向下位移；顯示時淡入並回到原位。
- 點擊任一收藏按鈕後顯示：`已收藏「{咖啡名稱}」，下次來門市時可以問問它。`
- 顯示 2.6 秒後自動隱藏；新提示需清除舊計時器。
- 收藏僅為前端提示，不保存資料、不建立購物車。

### 6.3 進場顯示

- `.reveal` 元素初始透明且向下位移 18px；加入 `.in` 後在約 0.65 秒內淡入並回到原位。
- 使用 `IntersectionObserver`，門檻為 `.12`；元素出現後停止觀察。
- 若不支援 IntersectionObserver 或使用者偏好減少動態效果，所有內容直接顯示。

## 7. 響應式版面

### 7.1 中型螢幕：`max-width: 840px`

- 導覽列高度約 68px，顯示漢堡按鈕和可展開選單。
- Hero 改單欄；文字在上，插畫在下；插畫高度約 280px並縮小咖啡枝葉。
- 品牌故事、沖煮區與門市區改為單欄堆疊。
- 選豆卡改兩欄，第三張卡橫跨兩欄。
- Footer 改為兩欄，品牌欄橫跨全寬。

### 7.2 手機：`max-width: 570px`

- 容器寬 `calc(100% - 34px)`，左右約 17px。
- Hero 最小高度 680px，主標約 40px，文字和插畫空間進一步縮小；隱藏插畫旁海拔標籤。
- 各主要區塊上下留白約 76px；品牌插畫視窗高度約 335px。
- 選豆標題列改直向，商品卡改單欄；卡片不再跨欄。
- 手沖示意高度約 325px，水流線、濾杯與分享壺縮小。
- 門市資訊格改單欄，分隔線調整以維持清楚閱讀。
- Footer 改單欄，版權列的兩段文字上下排列。

## 8. 無障礙與內容語意

- 使用繁體中文文件語系、單一 H1、分區 H2 與卡片 H3 建立清楚標題階層。
- 主要導覽使用 `<nav aria-label="主要導覽">`；菜單按鈕帶有 `aria-controls`、`aria-expanded` 和動態標籤。
- 純裝飾的 Hero、故事插畫及沖煮插畫不應被螢幕閱讀器重複朗讀；Hero 與沖煮插畫使用 `aria-hidden="true"`。
- Toast 使用 `role="status"`、`aria-live="polite"` 宣告動態訊息。
- 所有連結及按鈕需支援鍵盤操作並提供可見 focus 樣式。
- 遵循 `prefers-reduced-motion`，停用平滑捲動和進場位移動畫。

## 9. 後續修改指引

| 修改需求 | 對應位置 |
|---|---|
| 品牌名稱與首頁主張 | Header 品牌、Hero 標題與 Footer 品牌欄 |
| 咖啡故事與產地資訊 | `#story` 文案、山景標籤 |
| 商品名稱、風味或價格 | `#selection` 三個 `.coffee-card`；同步更新 `data-coffee` |
| 沖煮參數和步驟 | `#brew` 圖說與 `.method-list` |
| 門市聯絡資料 | `#visit` 資訊格及 Footer Contact 欄 |
| 品牌色彩 | CSS `:root` 色彩 Token 與插畫專用色 |
| 手機版尺寸或欄數 | `@media (max-width: 840px)` 和 `@media (max-width: 570px)` |
| 動態提示文案 | JavaScript `showToast()` 呼叫處 |

修改時需保留各錨點 ID、選單 ARIA 狀態、收藏按鈕資料值、Toast live 區域及減少動態效果支援。若增加表單或購物等功能，需明確定義資料送出和保存方式；現有頁面沒有電子報訂閱或結帳功能。
