# 山林特產網站｜網頁規格書

> 依據 `WebPage_11515146/outline/index.html` 逆向整理。本文記錄目前單頁網站的資訊架構、視覺規則、內容、互動與響應式行為，作為後續修改與重製的基準。實作細節如尺寸與色碼以原始 HTML/CSS 為準；本文未載明的商務流程不應自行假設。

## 1. 專案概述

- **產品名稱：** 山林特產
- **頁面型態：** 單頁式農產品牌介紹與當季商品展示頁
- **語系：** 繁體中文（`zh-Hant`）
- **品牌主張：** 嚴選友善環境種植的小農當季好物，提供新鮮、安心、實惠的產地滋味。
- **頁面標題：** `山林特產｜把山林的好，帶回日常`
- **頁面描述：** 山林特產，嚴選友善環境種植的小農當季好物，讓新鮮、安心又實惠的山林滋味走進日常。
- **主題色：** `#e7f6f8`
- **實作形式：** 單一 HTML 檔，CSS 與 JavaScript 內嵌；無外部圖片、字型、框架或套件依賴。

## 2. 目標與使用情境

訪客進入頁面後，應能快速理解品牌理念、瀏覽本週商品、透過導覽跳至相關區塊，並可使用前端示意的「加入購物袋」功能。頁面同時以小農故事與友善農業資訊建立信任。此頁目前沒有結帳、會員、庫存、配送或後端串接功能。

## 3. 全站視覺與版面系統

### 3.1 色彩

| Token | 色碼 | 用途 |
|---|---|---|
| `--sky` | `#e7f6f8` | 主視覺天空、圖示底色 |
| `--sky-strong` | `#8ccfdd` | 故事區引言邊線 |
| `--blue` | `#39899a` | 強調文字、眉標、互動色 |
| `--deep` | `#205965` | 品牌深色、主要按鈕、標題與購物袋 |
| `--ink` | `#263d3d` | 主要內文 |
| `--muted` | `#6d8180` | 次要說明文字 |
| `--cream` | `#fffdf6` | 頁面底色、卡片及提示卡 |
| `--leaf` | `#64865c` | 商品季節標籤 |
| `--line` | `#dce9e6` | 卡片、分隔線 |
| `--gold` | `#e7bd72` | 預留暖色 token |

其他區域色：商品區 `#f1f8f4`、故事區 `#e8f3ed`。陰影 token 為 `0 18px 45px rgba(37, 82, 84, .1)`。

### 3.2 字體、排版與容器

- 字體堆疊：`Noto Sans TC`、`PingFang TC`、`Microsoft JhengHei`、sans-serif；未載入網路字型，依系統字體呈現。
- 全站 `box-sizing: border-box`；內文行高 `1.7`；頁面平滑捲動（尊重減少動態偏好）。
- 桌面內容容器最大寬 `1160px`，左右總留白至少 `48px`；窄螢幕容器寬為 `calc(100% - 34px)`。
- 區段基礎上下內距 `92px`；中型手機以下 `72px`。
- 眉標為藍色、粗體、小型大寫英文、字距 `.2em`；區段標題置中，內文最大寬度約 `650px`。
- 卡片與按鈕使用圓角；主要互動按鈕採膠囊形狀，卡片圓角約 `17px`。

### 3.3 圖像風格

所有插畫均以 CSS 幾何形狀或系統 Emoji 呈現，不依賴圖片檔。主視覺為淡藍天空、同心圓、太陽、層疊山坡、梯田、小屋、樹與產地文字卡；小農故事以竹籃及蔬果 Emoji 組成。商品圖為柔和漸層背景搭配大尺寸蔬果 Emoji。若改用正式攝影或插畫，應維持自然、溫暖、友善農業與低飽和配色的方向，並保留替代文字。

## 4. 頁面結構與內容規格

頁面由上至下依序為：固定於頁面頂端視覺區的導覽列、主視覺、品牌理念、當季商品、小農故事、品牌資訊 CTA、頁尾。所有導覽皆為頁內錨點。

### 4.1 頂部導覽列

- `header.site-header` 絕對定位於頁面最上方，疊在主視覺上方；深青色文字，內容底線為半透明深青色。
- 桌面導覽列高度至少 `82px`；品牌標誌是圓框「山」字，旁邊顯示「山林特產」及英文副標 `FROM OUR HILLS TO YOUR HOME`。
- 導覽項目與目的地：`友善理念` → `#values`、`當季好物` → `#products`、`認識小農` → `#story`、`購物袋` → `#products`。
- 購物袋以膠囊外框呈現，內含初始數量 `0` 的圓形計數器。
- 小於等於 `760px` 時顯示漢堡按鈕，桌面文字連結隱藏。按鈕控制 `#navLinks`，應同步更新 `aria-expanded` 及「開啟／關閉導覽選單」標籤。
- 點擊行動版選單任一連結後關閉選單並還原 ARIA 狀態。
- 提供「跳至主要內容」skip link；平時移至畫面上方之外，鍵盤聚焦時顯示。

### 4.2 主視覺 Hero（`#top`）

- 背景淡藍 `--sky`，桌面最小高度 `710px`，垂直置中；內容為左右兩欄，間距 `32px`。
- 左欄眉標：`GOOD FOOD · KIND FARMING`。
- H1：`把山林的好，帶回日常。`，分行呈現；「日常」以藍色強調。桌面字級 `clamp(46px, 6vw, 76px)`，行高 `1.22`。
- 說明文：跟著季節認識土地，從用心耕作的小農手中，挑選新鮮、安心又實惠的當季好物。每一份選擇，都是對友善農業的支持。
- 主要 CTA「逛逛當季好物 →」連到 `#products`；次要 CTA「認識山林小農」連到 `#story`。
- 補充標語：`友善土地・當季採收・產地直送`。
- 右欄是 CSS 山景插畫，整體最小高度 `430px`。包含太陽、前後山、農田、小屋、樹；右下覆蓋提示卡「從產地開始，剛剛好。讓好食材回到餐桌」。插畫容器須有 `role=img` 及描述性 `aria-label`。

### 4.3 品牌理念（`#values`）

- 奶油白背景。置中眉標 `OUR PROMISE`、標題「好好種，也要好好分享」、說明「讓環境友善的耕作，遇見重視生活品質的你。」
- 三張等寬理念卡片，桌面三欄、卡片間距 `19px`；白底、細邊框、圓角 `17px`，內距 `25px`。每張卡片以淡藍圓形 Emoji 圖示開頭。

| 圖示 | 標題 | 說明 |

| 🌱 | 友善環境種植 | 支持珍惜土地與自然生態的耕作方式，讓每一季都能持續豐收。 |
| 🧺 | 當季新鮮直送 | 跟著產地與季節挑選，讓採收後的新鮮滋味更快抵達你的餐桌。 |

### 4.5 小農故事（`#story`）

- 淡綠底 `#e8f3ed`；桌面左右兩欄，比例 `.9fr / 1.1fr`、間距 `75px`，垂直置中。
- 左側 CSS 竹籃插畫，最小高度 `340px`；籃中 Emoji `🍊🍅🥬`，容器 `role=img` 並提供「盛裝當季蔬果的農產竹籃插畫」替代文字。
- 右側眉標 `GROWN BY PEOPLE`、標題「每一份好滋味，都有一雙用心的手。」、品牌與小農合作說明、左側藍色邊線強調文「買得安心、吃得新鮮，也讓小農的努力得到回饋。」
- 主要 CTA「一起支持友善農業 →」連到 `#products`。

### 4.6 品牌資訊 CTA

- 位於故事區後，與故事區共用淡綠底；深青色圓角資訊面板，白色文字，桌面左右排列。
- 標題「跟著季節，發現產地好物」；說明「常來看看本週小農新鮮採收的作物，讓餐桌多一點山林滋味。」
- 連結「瀏覽當季好物 →」指向 `#products`。

### 4.7 頁尾

- 上方細分隔線；桌面單列左右分散，內容為品牌「山林特產」、標語「友善土地，分享當季好滋味。」、`© {當前年份} 山林特產`。
- 年份由 JavaScript 使用瀏覽器當年動態填入。

## 5. 互動與狀態

1. 所有主導覽與 CTA 以原生錨點移動至對應區段；啟用平滑捲動（使用者設定減少動態時停用）。
2. 行動版漢堡選單以 `aria-expanded` 表示狀態；點擊連結後自動收合。
3. 加入購物袋按鈕每次點擊增加全站件數並更新狀態回饋，不進行頁面跳轉或重新載入。
4. 頁尾年份於載入時依本機瀏覽器年份更新。
5. 鍵盤聚焦的連結與按鈕顯示 `3px` 藍色外框，偏移 `4px`。
6. 按鈕 hover 有輕微上移或反白；尊重 `prefers-reduced-motion: reduce`，關閉平滑捲動並將 transition 降至近乎即時。

## 6. 響應式規格

| 視窗寬度 | 版面規則 |
|---|---|
| `> 760px` | 導覽列顯示完整連結；Hero 雙欄；理念與商品各三欄；故事雙欄；資訊面板與頁尾水平排列。 |
| `≤ 760px` | 導覽改漢堡選單；Hero 單欄、自然高度，插畫置於文案下方；理念與商品改兩欄；故事改單欄；區段內距降至 `72px`；資訊面板仍可水平排列。 |
| `≤ 520px` | 容器左右各約 `17px`；品牌字略縮；Hero 文案縮小、插畫高度 `280px`；理念與商品改單欄；商品圖高 `190px`；資訊面板改直向，CTA 移到文字下方；頁尾改直向排列。 |

手機 Hero 在 `≤760px` 時最小高度取消、上內距 `120px`、下內距 `55px`；`≤520px` 時上內距 `108px`。主視覺裝飾圓形在手機向下移動，避免干擾文字。山景各元素於最窄斷點縮小。

## 7. 無障礙與語意要求

- 文件語言設定為 `zh-Hant`；使用 `header`、`nav`、`main`、`section`、`article`、`footer` 語意區域，標題階層為單一 H1、各區 H2、卡片 H3。
- 導覽有 `aria-label`；主視覺與竹籃插畫提供圖像角色與文字替代；純裝飾 Emoji 設 `aria-hidden=true`；商品 Emoji 提供具體替代文字。
- 行動版選單按鈕須有 `aria-controls`、`aria-expanded` 及動態可理解的標籤。
- 購物袋件數與加入結果使用即時區域，讓輔助科技得知狀態更新。
- 提供跳至主要內容連結、清楚鍵盤焦點樣式、足夠文字對比及減少動態偏好支援。

## 8. SEO 與瀏覽器資訊

- `lang="zh-Hant"`、UTF-8、viewport 為裝置寬度及初始縮放 1。
- 設定描述、theme-color `#e7f6f8`、標題 `山林特產｜把山林的好，帶回日常`。
- 無社群分享圖、canonical、結構化資料或 favicon 規格。

## 9. 實作與修改邊界

- 當前設計由單檔 HTML/CSS/JS 構成，無外部資產；CSS 插畫和 Emoji 是視覺內容的一部分，若替換須維持語意替代文字。
- 商品價格、文案、錨點、色彩 token、斷點、卡片數量均為可直接核對的現況規格；後續變更應同步更新本文件。
- 購物袋僅為前端互動示意。若規格要擴充為實際電商流程，需另行定義商品明細、數量、庫存、配送、付款、錯誤與持久化行為；這些不屬於現行頁面。
- 本規格依 HTML/CSS/JS 靜態內容逆向整理；字型最終外觀會受使用者裝置可用字體影響。
